# Auxris RFCs

RFCs define the public contracts that implementations must follow. An RFC is accepted when it is merged into `main`; incompatible changes require a new version rather than silent reinterpretation.

| RFC | Subject | Status |
| --- | --- | --- |
| [0001](0001-evidence-taxonomy.md) | Evidence taxonomy and envelope | Proposed |
| [0002](0002-fingerprint-protocol.md) | Constellation fingerprint protocol | Proposed |
| [0003](0003-provenance-consent-policy.md) | Provenance, consent, and policy model | Proposed |
| [0004](0004-runtime-architecture.md) | Control plane and data plane | Proposed |
| [0005](0005-dataset-guard-api-benchmark.md) | Dataset Guard API and benchmark | Proposed |

Use a pull request to propose changes. The PR must describe compatibility, security, privacy, operational cost, and migration impact.
