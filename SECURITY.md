# Security policy

## Supported versions

Auxris is pre-alpha. Only the latest commit on `main` receives security fixes; there is not yet a stable supported release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's **Report a vulnerability** flow under the repository Security tab to start a private advisory with the maintainers. Include the affected version, impact, smallest safe reproduction, and any suggested remediation. Do not include private catalog media unless maintainers explicitly arrange an approved transfer.

Maintainers will aim to acknowledge a report within three business days, provide a preliminary assessment within seven, and coordinate disclosure after a fix is available. These are goals rather than a service-level agreement.

## Deployment warning

Pre-alpha Auxris is intended for local and controlled-network evaluation. Review `docs/THREAT_MODEL.md` before handling untrusted uploads. A match is technical evidence and must not be used as the sole basis for legal, employment, account, or content-removal decisions.
